📷 작업 사진 워터마크

사진은 원본 그대로 보관돼요. "저장" 또는 "공유"를 누르면 카테고리별로 정렬 + 워터마크 적용 후 세로로 이어붙인 이미지 1장으로 처리됩니다.

📖 사용 설명서

1. 작업 제목 입력

맨 위 칸에 작업 제목을 입력합니다. 오른쪽 🎤 버튼을 누르면 음성으로도 입력할 수 있습니다. (안드로이드 Chrome 권장)

2. 사진 촬영 / 업로드

  • 📷 촬영 — 카메라가 바로 실행됩니다.
  • 🖼 업로드 — 갤러리에서 여러 장 선택 가능합니다.
  • 각 항목마다 사진을 여러 장 추가할 수 있습니다.
  • 썸네일 오른쪽 위 × 를 누르면 삭제됩니다.

3. 저장 / 공유

두 버튼 모두 다음 과정을 동일하게 거친 뒤, 마지막 처리만 다릅니다.

  1. 각 사진 하단에 작업 제목 + 버튼을 누른 시각 워터마크 삽입
  2. 항목 순서(1→2→3→4)대로 정렬하고 구분 라벨 추가
  3. 전체를 세로로 이어붙여 이미지 1장으로 합성
  • 💾 저장 — 완성된 이미지를 폰(갤러리/다운로드 폴더)에 바로 저장
  • 📤 공유 — 공유 시트를 열어 카카오톡 · Teams · 메일 등으로 바로 전송 (파일로 남기지 않고 바로 보낼 때 사용)

4. 초기화

입력한 제목과 촬영한 사진을 모두 지웁니다.

⚠️ 참고사항

  • 모든 처리는 휴대폰 안에서만 이루어집니다. 서버로 전송되지 않습니다.
  • 브라우저를 닫거나 새로고침하면 사진이 사라집니다. 작업 후 바로 저장해 주세요.
  • 워터마크의 제목은 저장 버튼을 누른 시점의 제목이 적용됩니다.
  • 사파리에서 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
