📷 작업 사진 워터마크

사진은 원본 그대로 보관돼요. "저장" 또는 "공유"를 누르면 항목 순서대로 정렬 + 워터마크를 넣은 이미지 1장으로 만들어집니다.

📖 사용 설명서

1. 작업 제목 입력

맨 위 칸에 작업 제목을 적습니다. 오른쪽 🎤 버튼을 누르고 말하면 음성으로도 입력됩니다.

2. 사진 촬영 / 업로드

  • 📷 촬영 — 카메라가 바로 켜집니다.
  • 🖼 업로드 — 갤러리에서 여러 장 고를 수 있습니다.
  • 항목마다 사진을 여러 장 넣을 수 있습니다.
  • 사진 오른쪽 위 빨간 × 를 누르면 그 사진만 지워집니다.

3. 저장 / 공유

두 버튼 모두 아래 과정을 거친 뒤, 마지막 처리만 다릅니다.

  1. 사진마다 아래쪽에 작업 제목 + 누른 시각을 넣습니다
  2. 항목 순서(1→2→3→4)대로 정리하고 구분 제목을 붙입니다
  3. 전부 세로로 이어붙여 사진 1장으로 만듭니다
  • 💾 저장 — 완성된 사진을 휴대폰에 바로 저장
  • 📤 공유 — 카카오톡 · Teams · 메일 등으로 바로 보내기

4. 전체 지우기

제목과 사진을 모두 지웁니다. 실수를 막기 위해 두 번 확인합니다.

💾 자동 임시 보관

사진을 넣으면 휴대폰 안에 자동으로 임시 보관됩니다. 실수로 창을 닫아도 다시 열면 "이어서 하시겠습니까?" 안내가 뜹니다.

⚠️ 알아두실 점

  • 사진과 제목은 휴대폰 안에서만 처리되며, 인터넷으로 전송되지 않습니다. (접속 횟수를 세기 위한 숫자 신호만 오갑니다)
  • 워터마크의 제목과 시각은 저장 버튼을 누른 시점 기준입니다.
  • 브라우저 메뉴에서 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
