사진은 원본 그대로 보관돼요. "저장" 또는 "공유"를 누르면 항목 순서대로 정렬 + 워터마크를 넣은 이미지 1장으로 만들어집니다. 작업이 여러 건이면 상단 "현재 작업"을 눌러 오갈 수 있고, 각 작업은 따로 저장됩니다.
📁 작업 목록

📖 사용 설명서

1. 작업 여러 건 동시에 진행하기

상단 "현재 작업" 칸을 누르면 지금까지 만든 작업 목록이 나옵니다.

  • ➕ 새 작업 시작 — 새로운 작업을 만듭니다. 기존 작업은 그대로 보관됩니다.
  • 목록에서 작업을 누르면 그 작업 화면으로 전환됩니다. 찍어둔 사진과 제목이 그대로 남아있습니다.
  • A작업 하다가 B작업으로 넘어가도, 나중에 다시 A로 돌아오면 이어서 촬영할 수 있습니다.
  • 완료된 작업은 목록에서 휴지통 아이콘으로 삭제합니다.

2. 작업 제목 입력

제목 칸에 적습니다. 오른쪽 🎤 버튼을 누르고 말하면 음성으로도 입력됩니다.

3. 사진 촬영 / 업로드

  • 📷 촬영 — 카메라가 바로 켜집니다.
  • 🖼 업로드 — 갤러리에서 여러 장 고를 수 있습니다.
  • 사진 오른쪽 위 빨간 × 를 누르면 그 사진만 지워집니다.

4. 저장 / 공유

지금 열려 있는 작업의 사진들을 아래 순서로 처리합니다.

  1. 사진마다 아래쪽에 작업 제목 + 누른 시각을 넣습니다
  2. 항목 순서(1→2→3→4)대로 정리하고 구분 제목을 붙입니다
  3. 전부 세로로 이어붙여 사진 1장으로 만듭니다
  • 💾 저장 — 완성된 사진을 휴대폰에 바로 저장
  • 📤 공유 — 카카오톡 · Teams · 메일 등으로 바로 보내기

5. 이 작업 지우기

지금 열려 있는 작업의 제목과 사진만 지웁니다. 다른 작업에는 영향 없습니다.

💾 자동 보관

모든 작업은 휴대폰 안에 자동으로 보관됩니다. 창을 닫아도, 다시 열면 마지막으로 보던 작업이 그대로 남아있습니다.

⚠️ 알아두실 점

  • 모든 작업은 휴대폰 안에서만 처리되며, 사진이 인터넷으로 전송되지 않습니다.
  • 워터마크의 제목과 시각은 저장 버튼을 누른 시점 기준입니다.
  • 브라우저 메뉴에서 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
